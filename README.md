# Оптимизатор контекста Matreshka

**Навык для анализа и оптимизации контекста AI-агентов: измерение расхода токенов, аудит skills и MCP, оптимизация инструкций и результатов инструментов, навигация по большим проектам, проверка эффективности изменений и интеграция с Matreshka Agent.**

Технический идентификатор навыка: `$context-optimizer`.

## Зачем нужен проект

Цель проекта — уменьшать расход контекста и токенов без ухудшения качества работы AI-агента.

Оптимизация считается успешной только тогда, когда одновременно выполняются условия:

- контекстный и/или токенный расход снижается;
- точность и полнота результата не ухудшаются;
- число повторных шагов и исправлений не растёт;
- агент не начинает чаще читать неправильные или лишние файлы;
- нужная информация не теряется;
- изменение можно проверить и, при необходимости, откатить.

## Базовый цикл

~~~text
MEASURE
  ↓
DIAGNOSE
  ↓
CLASSIFY
  ↓
RECOMMEND
  ↓
APPROVAL
  ↓
APPLY
  ↓
RE-MEASURE
  ↓
VERIFY
  ↓
KEEP / ROLLBACK
~~~

## Принципы

1. **Сначала измерение, потом оптимизация.**
2. **Никаких выдуманных token counts.** Каждый показатель обязан содержать источник и тип измерения.
3. **Read-only по умолчанию.** Изменения выполняются только после отдельного этапа предложения и подтверждения.
4. **Reversible-first.** Перед изменением сохраняется возможность отката.
5. **Одна оптимизация — одна проверяемая гипотеза.**
6. **Меньше токенов не равно лучше**, если выросло число ошибок, повторных чтений или шагов.
7. **Внешние инструменты используются через адаптеры**, а не копируются без необходимости.
8. **Весь пользовательский интерфейс, отчёты и инструкции проекта — на русском языке.**

## Внешние инструменты

- **CodeBurn** — основной кандидат для измерения runtime-использования, анализа сессий и поиска потерь.
- **Caveman** — опциональный внешний механизм recoverable-компрессии и источник методологических идей. Engine-части не копируются в этот проект.
- **Graphify** — опциональная project-local зависимость для навигации по средним и большим репозиториям. Код Graphify внутрь проекта не копируется.
- **CShark-Hub/context-audit** — независимый методологический референс для схемы аудита и approval-процесса, не источник истины.

## Текущая реализация

Gate 0–2 зафиксированы.

Read-only MVP Gate 3 уже имеет:

- компактный `skills/context-optimizer/SKILL.md`;
- environment scan;
- точный учёт static bytes;
- поиск точных дублей между instruction files;
- инвентаризацию skills и scope collisions;
- проверку наличия Graphify graph;
- detection внешних CLI;
- machine-readable schemas;
- smoke test.

В v0.1 **ничего автоматически не изменяется**.

Следующий шаг — пилот read-only MVP на реальном проекте, затем CodeBurn Adapter.
