## Новый автономный шаг

С `--save` сохраняются отдельные snapshots, нормализованный аудит, Markdown/HTML и STATE.
Raw transcript/tool arguments не переносятся на диск этим слоем. Используются приватные
права файлов там, где ОС их поддерживает, lock, атомарная замена файлов, проверка принадлежности
проекту и запрет symlink/junction в путях состояния. Общие шаблоны ключей скрываются;
это не гарантированное обнаружение всех возможных секретов. HTML экранирует входной текст.

Память проекта: предпросмотр → подтверждение конкретного содержания → backup → вставка только
управляемого блока. Другие байты, включая существующие CRLF, сохраняются. Повторная вставка идемпотентна.
Смена исходного файла делает старое подтверждение недействительным. Рекомендации не становятся
инструкциями и не превращаются в разрешение на mutation.

`finish` сравнивает static bytes с сохранённым baseline и оставляет эффект по токенам UNVERIFIED.
Уменьшение инструкций не доказывает улучшение качества или уменьшение стоимости полной задачи.

## Архив автора

SHA-256 загруженного архива: `adebbdcc7ce0abbb1f4e32774e33fb5ab655aa95ee5b67b3d423260bfa590ba4`.
Статически прочитаны оба файла: инструкция (16 081 байт) и Python-аудитор (29 314 байт).
Код автора не запускался и не копировался в runtime.

Принято: сначала задача пользователя; приоритет риска/обратимости; отдельное согласие на каждое
изменение; сохранённый отчёт; нет наблюдений ≠ не используется; свежий навык нельзя объявлять
ненужным только по короткому окну наблюдения. Не принято: обязательная сторонняя установка,
принудительное сокращение ответов и обещание проверки через несколько дней без реально настроенного
механизма. В архиве есть ссылки на файлы полного пакета вне архива; перенос инструкции целиком
создал бы неработающие ссылки.

## Повторное сопоставление исходных подходов

Проверены документация локальных provider-журналов, подход к восстановимому сокращению результатов
и навигация по зависимостям. Принцип: происхождение и семантика метрик важнее совпадения чисел.
Отдельно зафиксировано: наша карта областей НЕ является AST-графом импортов/вызовов. Не приписывать
ей такие возможности. Рекомендации сокращать результаты без доступа к оригиналу не автоматизировать.

## Что ещё нельзя объявлять готовым

- Полная безопасность прежнего универсального change executor: необходим отдельный проход по
  валидации change_id/params, символьным ссылкам и целостности backup до rollback.
  Новый автономный шаг автоматически не вызывает этот executor.
- Полнота provider counters на fork/resume, cross-file streaming dedup Claude, неизвестные схемы
  бинарной телеметрии и активные SQLite/WAL базы. Новые тесты не заменяют пользовательский корпус.
- Расширенные каталоги пользовательских правил, scope/precedence и `.gitignore`-совместимый обход.
- Установщик и реальные быстрые команды во всех четырёх host UI: следующий этап.
- `finish` при принудительном закрытии приложения: без проверенного hook не обещается.
