# Ревью v0.4, шаг 2 — установка и быстрые режимы

Основа: `2ae41045adf0668246fb51a6be2d95597b1b1184`, tree `563423a96b93e622fa9dcfa8a535d1bab8592307`.
Локальные исходники первого шага сверены с этим tree до внесения изменений.

## Выполнено

Установщик стандартной библиотеки: install/update/uninstall/doctor; project/user области;
отдельный глобальный профиль Antigravity CLI; один физический skill для общей `.agents/skills`.
Нет сети, pip/npm, запуска редактора, изменения hook/config/permissions, автоматической правки Git.
Перед записью — предпросмотр и подтверждение хеша пакета/пути/текущей установки.

Manifest хранит версии формата и пакета, SHA-256 файлов, список каталогов. Изменённые,
добавленные или отсутствующие файлы останавливают update/uninstall. Чужая папка без manifest
не усыновляется и не перезаписывается. Хеши не являются электронной подписью и не подтверждают автора.

Смена установки выполняется через staging и сохранение прежнего каталога в отдельной резервной области.
При ошибке активации старая копия восстанавливается, если это не затрёт возникший новый target.
После сбоя записи журнала уже активированная установка не удаляется автоматически: NEEDS_REVIEW.
При прерывании процесса сохраняются журнал и lock; нет автоматического опасного снятия блокировки.
Две замены каталогов не являются одной атомарной транзакцией ОС; на время обновления агент нужно остановить.

Quick entrypoint: allowlist режимов, настоящий project root, отсутствие shell/eval, автоматической
установки и подмены Cursor-чтений журналами другого provider. Status без снимка сообщает об отсутствии,
а не запускает новый полный аудит. Входная строка из чата — данные, не команда shell.

Пакет содержит лицензию; резервная область исключена из аудита/карты. Добавлены известные
каталоги навыков Cursor и Antigravity. При штатном quick/peer entrypoint bytecode cache не создаётся.

## Проверки и границы

Регрессионные тесты проверяют реальные временные каталоги, русские пути с пробелами, независимый cwd,
install/update/uninstall, сохранность аудита и чужих навыков, manifest, stale approval, ссылки/hardlinks,
сбой активации, lock и незавершённые операции. Установленный quick запускается отдельным Python-процессом.

Это не запуск Codex, Claude Code, Cursor или Antigravity UI. Соответствие путей и механизмов вызова
сверено с первичной документацией 24 сентября 2026; источники — в installation.md.
Фактическое появление команды в конкретном UI, политики управляемых машин и облачный перенос
требуют пользовательской приёмки. Установщик не является sandbox против враждебного процесса
с правами того же пользователя, меняющего файловую систему между проверкой и записью.
