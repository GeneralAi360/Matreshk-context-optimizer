# SOURCE-001 — обучающий урок

## Роль источника

Источник идеи: оптимизацию контекста начинать с измерений, а не с универсального списка советов.

## Извлечённые принципы

- сначала получить картину расхода;
- проверять MCP/connectors;
- поддерживать гигиену skills;
- не раздувать project memory/instructions;
- контролировать большие tool outputs;
- использовать graph navigation на больших codebases.

## Что НЕ переносится как факт

Конкретные числа overhead из демонстрации автора не являются универсальными значениями.

Optimizer должен измерять конкретную среду.
