# SOURCE-002 — CodeBurn

Repository: https://github.com/getagentseal/codeburn

## Роль

Основной внешний кандидат на runtime measurement.

## Подтверждённые полезные поверхности

Upstream предоставляет, среди прочего:

- `codeburn overview`;
- `codeburn audit`;
- `codeburn context`;
- `codeburn optimize`;
- JSON output для части отчётов;
- apply/undo/report механизмы;
- provider integrations.

## Что берём

- measurement-first;
- session/context telemetry;
- detectors как источник evidence;
- re-measure/undo methodology.

## Что не делаем

- не форкаем без необходимости;
- не копируем весь detector engine;
- не считаем оценки CodeBurn собственной provider telemetry без provenance.
