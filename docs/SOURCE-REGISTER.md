# Реестр происхождения решений

Цель реестра — отделять идеи из обучающих материалов от собственной реализации проекта.

## SOURCE-001 — обучающий урок

**Тип:** `REFERENCE_ONLY + IDEA_ADAPTED`

Из урока взяты только общие инженерные принципы:

- сначала измерять, затем оптимизировать;
- отдельно проверять инструменты/MCP;
- поддерживать гигиену skills;
- контролировать размер project instructions;
- уменьшать чрезмерный ingress tool outputs;
- для больших проектов использовать структурную навигацию;
- после изменения обязательно переизмерять и проверять качество.

Конкретные цифры и настройки из демонстрации автора не считаются универсальными фактами.

## Собственная реализация

**Тип:** `INDEPENDENT_IMPLEMENTATION`

Самостоятельно реализованы:

- native provider telemetry;
- measurement provenance model;
- static audit;
- skills/MCP/instruction audit;
- native project map;
- context-ingress analysis;
- trigger policy;
- finding contract;
- reversible changes;
- Optimization Ledger;
- Matreshka Agent bridge/dashboard contract;
- before/after acceptance methodology.

Текущий runtime навыка не требует сторонних оптимизаторов и не устанавливает их.
